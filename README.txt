AUREA — версия 2, вдохновлённая подачей современных digital-агентств.

БЫСТРЫЙ ЗАПУСК
1. Откройте index.html в браузере.
2. Для публикации загрузите всю папку на хостинг с сохранением структуры.

КАК ПОСТАВИТЬ ВИДЕО В HERO
- Поместите файл MP4 сюда: assets/video/gold-liquid.mp4
- Рекомендуется: 1920×1080 или 1920×1200, 8–15 секунд, без звука, до 8–12 МБ.
- Если видео отсутствует, остаётся анимированный CSS-фон + постер.

КАК ЗАМЕНИТЬ ПОРТФОЛИО
- case-thermoprom.svg
- case-invite.svg
- case-3d.svg
Можно заменить на JPG/WebP/AVIF, поменяв src в index.html.

ПЕРЕД ПУБЛИКАЦИЕЙ
- заменить AUREA на итоговое название;
- заменить hello@example.ru;
- прописать ссылки Telegram/VK;
- добавить canonical и реальный домен в sitemap.xml;
- заменить плейсхолдеры портфолио реальными работами;
- при необходимости подключить форму через свой backend/CRM.

ДОСТУПНОСТЬ
- skip-link;
- фокус клавиатуры;
- prefers-reduced-motion;
- семантические секции и подписи;
- мобильное меню с aria-атрибутами.

Анимации используют GSAP через CDN. Без GSAP контент остаётся доступным и видимым.
